# Legacy documentation

These documents describe the "safety-first control plane" era (versions 0.4–0.61) and features removed in the ADR-001 pivot: the Keel Notes adapter, signed fleet agents, migration staging, router checkpoints, and the hand-written Uptime Kuma / Pi-hole application adapters. They are kept for history only; nothing here describes the current product. See [`docs/ROADMAP-V2.md`](../ROADMAP-V2.md) and [`docs/DECISIONS.md`](../DECISIONS.md).
