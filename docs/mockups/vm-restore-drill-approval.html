Exact changes
  1. Restore the exact encrypted restic snapshot into a server-generated temporary workspace
  2. Reverify its manifest, every SHA-256 checksum, exact size, and each qcow2 disk structure
  3. Grant QEMU temporary access only to the verified restored disks
  4. Boot a generated transient libvirt domain with no network interface
  5. Destroy the domain, remove generated UEFI state, revoke disk access, and verify workspace cleanup
  6. Promote only this backup record to protected after every check passes
Required verification
  1. Exact repository, snapshot id, source path, and server-generated tags
  2. Transient running domain with zero network interfaces
  3. Two QEMU guest-agent pings while the restored guest remains running
  4. Domain, UEFI NVRAM, temporary permission, and workspace cleanup
WarningsThe source guest must contain and enable qemu-guest-agent or this drill will fail safely.The job can run for hours while restic restores and verifies the disks.No-network boot proves guest-agent health, not application-level network services.
Recovery boundaryFailure never promotes protection. BoxPilot stops only the generated transient domain, removes only its generated UEFI state, revokes temporary QEMU access, and preserves restored files root-only for inspection.
