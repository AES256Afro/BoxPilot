Suggested

what you may
be missing
  • lookSweep the running server, not only the code

    Three of the day's best findings came from looking at the live pages. A monthly walk of the real box would keep finding what reading cannot.

  • agentsThe agents are the weakest visible part

    Every one of the 28 cards said a limit was reached, and the digest was raw tool output. M58 is first in the plan for that reason.

  • today17 Ubuntu updates are waiting, security fixes among them

    Home has shown them all day. One click on Install, and no restart is needed.

  • keyNo release key is set

    Repair now says so: an update is built from whatever the GitHub tag points at. Setting a key on System, BoxPilot update closes that.

  • disk172 old database copies hold 1.1 GB

    Every upgrade adds 35 MB and nothing removes one. Pick a number to keep.

  • rhythmReleases outrun the public demo

    The demo is a frozen copy deployed by hand. A deploy step in the release workflow would end the drift.

  • proofRestores are tested per app, not as a whole

    The rebuild still stages network, firewall and mounts for review only. One real bare-metal drill a quarter would prove the claim.

    The Zulip connect script's new refusals need a live Zulip to prove. The gateway's sandbox was checked on the server: it can no longer see the helper's socket.

Five decisions that are yours

  1. May a recovery-code sign-in set a new password? Today it cannot, so the last resort still cannot approve anything high-risk. The safer design spends a second code as proof.
  2. Should registering a passkey ask for the password? It is a documented trade-off; someone at an unlocked browser can add their own key.
  3. How many old database copies to keep. 172 now, three of them from today. Keeping the newest ten would return about 1 GB.
  4. The tier of the seven apps that only read the Docker socket. Medium today; a read-only socket mount still answers the full Docker API.
  5. ADR-018, deduplicated app backups. Proposed since October and still waiting.
